## 내용

신경망 연산을 GPU kernel로 직접 구현하는 과제다. normalize, ReLU, padding, im2col, 행렬곱, convolution, pooling, fully connected kernel을 작성하고 VGG16 forward 경로에서 im2col과 행렬곱을 호출하도록 연결했다. 고수준 모델 연산을 thread와 메모리 접근, 행렬 계산으로 내려가 다룬 경험이다.

## 한계

- shared memory를 쓰는 별도 행렬곱 함수를 정의했지만, 검사한 파일에서 그 kernel을 호출하는 경로는 찾지 못했다. 최적화가 실제 실행 경로에 적용됐다고 말하지 않는다.
- 보고서에 성능 향상 서술은 있지만 GPU 사양 · 입력 · baseline · 측정 시간이 함께 있는 표가 없어 가속 배수를 적지 않는다.
- forward 중심 구현이며 학습 전체를 CUDA로 구현한 것이 아니다.
