## 문제

생성모델 네 계열이 각각 무엇을 학습하고 어떻게 샘플을 만드는지, 수식을 코드로 옮기며 확인했다. "네 종류를 수강했다"가 아니라 목적함수와 샘플링 과정을 직접 구현했다는 것이 이 묶음의 요점이다.

## 구현 범위

| 과제 | 직접 채운 부분 | 남아 있는 결과 |
| --- | --- | --- |
| MADE | masked linear · 연결 mask · Bernoulli NLL · 순차 샘플링 | 학습 loss · 생성 이미지 |
| CNN VAE | encoder/decoder · reparameterization · reconstruction · KL · 중요도 샘플링 평가 | 학습 · 평가 loss · 생성 이미지 |
| DCGAN · WGAN-GP | G/D · gradient penalty · 학습 구간 · FID · latent interpolation | 두 모델의 샘플 · FID |
| DDPM · Flow Matching | 시간 임베딩 · U-Net forward · noise/velocity 목표 · 역과정 · Euler 샘플링 | 20 epoch 학습 · 10/100/1,000 step 샘플 |

## 한계와 다음 단계

- DDPM sampler는 timestep 간격을 벌리면서 한 단계 역과정 식을 그대로 쓰는 형태다. 적은 step의 결과 차이를 모델 계열의 우열로 해석하기 전에 sampler 비교 조건을 검토해야 한다.
- 서로 다른 목표의 loss 값을 직접 비교하지 않는다.
